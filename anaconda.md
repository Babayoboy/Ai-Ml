conda activate :- ***Activates the base env***
conda list :- ***Lists all the packages***
conda env list :- ***List all the env***
conda create -n {name} :- ***Creates a new env***
conda env remove -n {name} or conda remove -n {name} --all :- ***Remove the env***
conda remove -n {name} {pacakage name} :- ***Remove the named package***
conda install {package name} :- ***installs the package***
